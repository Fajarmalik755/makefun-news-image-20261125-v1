stories from 7 regions — masthead, KPI strip, 3 hero stories, 10 cards, a world map and a
27-story list, plus a DATE CHECK footer showing what was left out and why.

Run `python3 main.py` to regenerate `entry.png` (stdlib only, deterministic).
